# Ashen Hollow

A dark, hand-drawn-style metroidvania. Explore a connected world of twelve rooms across four zones,
fight with a nail-style sword (forward, up, and downward pogo strikes), and unlock new routes with abilities.

- Movement: run, jump (variable height), **double jump** (Wisp Wings), **dash** (Shade Dash)
- Sword: forward / up / down strikes, pogo off enemies and spikes, break cracked walls
- Soul + Focus heal, benches (save + heal), 3 hidden Heart Cores, sword upgrade (Edge of Night)
- 5 enemy types, **4 bosses** with different multi-phase attack patterns
- Map screen, auto-save, synthesized sound, touch controls

Keys: arrows/WASD move, Z jump, X sword, C dash, V focus (heal), M map, P pause.

`npm test` runs a physics reachability test (ability gates) and a full headless playthrough of rooms, bosses, saving and the ending.
